# Screenshots

Drop your images here using these exact filenames — the main `README.md` already links to them:

| Filename | Shot |
| --- | --- |
| `dashboard.png` | Dashboard with stats, donut and service chart |
| `jobs.png` | Jobs list with search and filters |
| `job-form.png` | Job modal — rooms, services, totals |
| `address-map.png` | Address autocomplete with the map preview open |
| `schedule.png` | Schedule (calendar view reads best) |
| `price-list.png` | Price list |
| `mobile-dashboard.png` | Dashboard on a phone-width viewport |
| `mobile-job.png` | Job detail on a phone-width viewport |

Tips:

- Capture desktop shots at **1440×900** so they all line up at the same width.
- For the mobile pair, use DevTools device mode at **390×844** (iPhone 14).
- Use the seeded demo data — real client names and phone numbers should not go in a public repo.
- PNG for UI. Keep each file under ~500 KB.
- A short screen recording exported as `demo.gif` is worth more than any single screenshot; add it under
  the Screenshots heading if you make one.
